Features

Everything OpenAI Codex, one glance away.

Recent chats, any project

Four keys show your latest local Codex chats across every project, with titles that wrap across the key.

A glow that follows Codex

Blue pulse while it works, amber when it asks for approval, green when a turn ends, coral on interruption.

One-press dictation

Press to record, press to stop. Codex does the transcribing and leaves the draft unsent in the message box.

Open, new chat, new panel

Jump into the Codex sidebar, start a chat, or open a Codex editor panel without touching the mouse.

Allowance on the Infobar

See how much of your five-hour and weekly limits remain, plus the tokens of the latest request.

Approvals stay yours

Sidekick never approves, denies or sends anything. Decisions stay in Codex, where you can read them.

Status you can feel

Know what Codex is doing without switching windows.

Hooks report what Codex is doing, from any local session. Sidekick turns that into color, so you can start a long task, work elsewhere, and see when it needs you.

  • Working a pulsing blue glow while a turn runs.
  • Approval requested amber, so you know Codex is waiting for you.
  • Turn ended a brief green glow when Codex finishes.
  • Interrupted coral when a turn is stopped.

Get started

Installed in five minutes.

You need macOS 13+, Stream Deck 7.6+ with a Stream Deck Neo, VS Code with the official OpenAI Codex extension, and Node.js 22.18+.

  1. Install both pieces. Download the .streamDeckPlugin and .vsix from Releases. Double-click the plugin to install it. In VS Code choose Extensions → … → Install from VSIX… and reload the window.
  2. Open a folder in VS Code. Sidekick connects it and installs its hooks into ~/.codex/hooks.json automatically. An existing hooks file is never overwritten; you get a draft to merge instead.
  3. Trust the hooks. In the Codex sidebar open Codex Settings → Hooks and review the eight Sidekick hooks. Send a message in any chat and its key starts to glow.
  4. Arrange your Neo. Chat Activity 1–4 on the top row, Open Codex, New Chat, New Panel and Dictate below, and Codex Usage on the Infobar.
  5. Allow dictation. Enable Stream Deck in System Settings → Privacy & Security → Accessibility and allow VS Code to use the microphone when macOS asks.
# or build from source
npm ci
npm test
npm run package:neo   # Stream Deck plugin
npm run package:vsix  # VS Code extension

Privacy

Local by design.

Sidekick never sends anything over the network, and it records as little as it can.

Redacted logOnly event names, timestamps, hashed IDs and token counts. Never prompts, paths or transcripts.
No decisionsHooks are read-only. Sidekick cannot approve, deny or change what Codex does.
Fixed commandsOnly a short allowlist of Codex actions can ever be requested over the local socket.
Careful dictationThe helper clicks one verified Codex microphone, never reads text or audio, and then puts your pointer back.

Honest limits. macOS only. Dictation finds Codex's microphone by its accessibility label, so a Codex redesign can break it until Sidekick is updated. Glow colors are observations from hooks, not live state, and only one VS Code window can be connected at a time.

# Codex Sidekick

See recent Codex activity and open chats from Stream Deck Neo.

1. Open a trusted local folder in VS Code.
2. Run **Codex Sidekick: Set Up Chat Activity**.
3. In **Codex Settings → Hooks**, review and trust the Sidekick hooks, then send a Codex message.

Run **Codex Sidekick: Toggle Connection for This Workspace** to connect or disconnect the current folder. Keep one Sidekick workspace connected when using the hardware keys. Use **Codex Sidekick: Show Diagnostics** to check which Codex actions are available in the window.

Sidekick shows recent hook activity and leaves approval decisions in the official Codex sidebar.

Press a chat key to open that exact conversation in the Codex sidebar. Confirm VS Code's link-opening prompt on first use and choose to remember your choice. Chat selection uses Codex's internal conversation route, which may change in future versions.
